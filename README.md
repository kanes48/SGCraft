# SGCraft

A Minecraft Fabric mod that adds two new weapons to the game: the **Shotgun** and **Sniper Rifle**.


## Requirements

* **Minecraft 26.2**
* **Fabric Loader**
* **Fabric API**

> **Note:** SGCraft is built specifically for Minecraft 26.2 on Fabric. Make sure you are using the corresponding versions of Fabric Loader and Fabric API.

## Installation

1. Download the latest release from the [SGCraft Releases](https://github.com/kanes48/SGCraft/releases/tag/SGCraft) page.
2. Download the `.jar` file from the latest release.
3. Place the `.jar` file into your Minecraft `mods` folder.
4. Launch Minecraft using the appropriate Fabric installation.

## Weapons

### Shotgun


**Controls:**

| Action       | Control                 |
| ------------ | ----------------------- |
| Fire         | Right Click             |
| Shotgun Jump | Hold Space while firing |


### Sniper Rifle


**Controls:**

| Action | Control     |
| ------ | ----------- |
| Scope  | Right Click |
| Fire   | Left Click  |

## Configuration

The delay between shots can be configured independently for each weapon using commands.

### Shotgun Delay

```text
/shotgundelay [ticks]
```

### Sniper Delay

```text
/sniperdelay [ticks]
```


## Creative Mode

Both weapons are available in the **Weapons** Creative Mode tab.
